Компиляция файла `hello_world.c`

`gcc -Wall -Werror -O2 -g -std=gnu17 hello_world.c -o app`

`-Wall -Werror` - более детальная диагностика на ошибки
`-O2` - оптимизация кода
`-g` -  включение отладочной информации
`-std=gnu17` - использование стандарта C-17 с расширениями GNU
`-o app` - создать исполняемый файл с именем `app`

Запуск программы в Linux:
`./app`

Посмотреть код последней завершившейся программы в Linux:
`echo $?`

`libc` - стандартная билиотека функций языка С, содержит заголовки, например `stdio.h`

Есть ещё другие заголовки: 

- `string.h`
- `math.h`
- `stdlib.h` - работа с памятью
- `time.h`
