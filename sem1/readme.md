Компиляция файла `hello_world.c`

`gcc -Wall -Werror -O2 -g -std=gnu17 hello_world.c -o app`

`-Wall -Werror` - более детальная диагностика на ошибки
`-O2` - оптимизация кода
`-g` -  включение отладочной информации
`-std=gnu17` - использование стандарта C-17 с расширениями GNU
`-o app` - создать исполняемый файл с именем `app`

Запуск программы в Linux:
`./app`

Посмотреть код последней завершившейся программы в Linux:
`echo $?`

0) `bool` / `_Bool`

- C99: `_Bool` с `_True` / `_False`

- `stdbool.h`

- входит в стандарт C23

1) `char`

- он знаковый или нет? может быть и таким, и таким, это implementation defined, то есть зависит от компилиятора и аппаратной платформы! например, на x86 процессорах `char` - знаковый, а на ARM - беззнаковый

- `-fsigned-char` / ` -funsigned-char` - принудительно задать знаковость `char` для компилятора `gcc` / `clang`, но нет гарантий, что интерфейсы стандартной библиотеки С не поломаются

- для остальных типов явное указание `signed` ничего не меняет
